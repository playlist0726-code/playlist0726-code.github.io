INTERACTIVE STORY · COURSE PROJECT

The Missing Hours

A small game about the choices a day loses when collecting water takes time.

Play the demo ↗Source & setup ↗
Role
Interaction design and AI-assisted frontend development within Global Career Accelerator coursework.
Build
HTML · CSS · JavaScript · Node test runner
Status
Published educational prototype

The question

An awareness message can be easy to skim. Can an interaction let someone experience competing demands on a limited day?

What I built

A responsive time-allocation game with three difficulty levels, draggable or keyboard-operable activity tokens, feedback, and a results screen.

Design & build decisions

01

Make the trade-off playable

A limited time budget turns an abstract constraint into a decision the player makes.

02

Keep controls inclusive

Keyboard interaction and reduced-motion support accompany the visual interface.

03

Explain the result

The end state connects choices back to the awareness theme instead of reporting only a score.

Evidence

The published demo, game-rule tests, and desktop/mobile screenshots are available in the public repository.

What I learned

A small interaction can carry a story when the rule itself expresses the subject.

Current scope

A charity: water-inspired student project, not commissioned work or an official organizational campaign. Gameplay is an educational simplification.

Next question

Observe whether first-time players understand the time constraint without additional explanation.
