# Junsu (Michael) Kim — Selected Work

A portfolio connecting filmmaking, creative AI tools, games, and product work.

**[Open portfolio](https://playlist0726-code.github.io/)** · [Film portfolio](https://michael-kim-creative-portfolio.starbuild4590.chatgpt.site) · [Project index](https://playlist0726-code.github.io/projects/)

## Structure

- `index.html`: selected work, background, and contact.
- `projects/`: six project case studies and a broader index.
- `assets/`: project images copied from the corresponding public project or published portfolio.
- `style.css`: responsive layout, focus states, and reduced-motion support.

Buildless HTML and CSS. No API keys, analytics, external fonts, or packages are required.

## Preview

```sh
python3 -m http.server 8766
```

Open `http://localhost:8766`. The repository root is published through GitHub Pages. Project links use stable case-study paths while preserving each product’s own deployment address.

## Content standard

Label prototypes and coursework explicitly. Keep team contributions distinct from individual work. Do not claim runtime AI, customer metrics, awards, employment, or production functionality that has not been established.
